You are tasked with checking for drug–drug interactions between the following drugs only:
${drug}

Instructions

Compare every unique pairwise combination between the listed drugs.

Example: Drug A vs Drug B, Drug A vs Drug C, Drug B vs Drug C.

Do not check interactions with drugs not listed.

Do not repeat combinations (e.g., include Drug A vs Drug B, but not Drug B vs Drug A).

Each interaction must include:

"drug1" – first drug name

"drug2" – second drug name

"description" – brief clinical explanation of the interaction

"severity" – one of: Critical | Serious | Moderate | Mild

Response Format

Respond only with valid JSON, no extra text:

{
  "interactions": [
    {
      "drug1": "Drug A",
      "drug2": "Drug B",
      "description": "Brief explanation of the interaction",
      "severity": "Critical|Serious|Moderate|Mild"
    }
  ],
  "severity": "Critical|Serious|Moderate|Mild|null"
}

Rules

If interactions exist:

List all unique pairs with their details under "interactions".

Set the root "severity" to the most severe interaction found.

If no interactions are found, return:

{
  "interactions": [],
  "severity": null
}

Severity Definitions

Critical – Immediate Action Required (Contraindicated)

Serious – Use Alternative (Avoid if possible)

Moderate – Monitor Closely (Adjust dose or monitor)

Mild – No Special Action Required (Minimal concern)
